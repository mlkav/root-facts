# RootFacts - AI-Powered Vegetable Recognition & Fun Facts

RootFacts is a Progressive Web App (PWA) that uses machine learning to identify vegetables from camera input and generates interesting facts using generative AI. It works offline, can be installed on desktop or mobile devices, and provides an engaging way to learn about vegetables.

## Features

- Real-time Vegetable Detection: Uses TensorFlow.js to classify vegetables from live camera feed with configurable FPS and confidence threshold.
- Generative AI Facts: After detection, a unique fun fact is generated using Transformers.js (LaMini-Flan-T5-77M) with dynamic tone selection (Normal, Funny, Professional, Casual).
- Adaptive Backend: Automatically detects WebGPU support and falls back to WebGL (TensorFlow) or WASM (Transformers) for maximum compatibility.
- Offline Capable: All assets, including AI models, are cached via Service Worker (Workbox) for full offline functionality.
- Installable PWA: Full Web App Manifest with icons, splash screens, and "Add to Home Screen" support.
- Copy to Clipboard: One-click copy of generated facts.
- Responsive Design: Optimized for both mobile and desktop devices.
- Real-time Status Indicators: Shows download progress for AI models with separate encoder/decoder percentages.

## Technologies Used

- Frontend: Vanilla JavaScript (ES6+), HTML5, CSS3
- Machine Learning:
  - TensorFlow.js - Vegetable classification model
  - Transformers.js (LaMini-Flan-T5-77M) - Text generation (fun facts)
- Build Tools: Webpack 5, Babel
- PWA & Offline: Workbox Webpack Plugin, Web App Manifest
- Deployment: Netlify (or any static hosting)

## Prerequisites

- Node.js (v22.22 recommended) and npm or yarn
- Modern browser with camera access (Chrome, Edge)
- For offline use, first load the app online to cache models

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mlkav/rootfacts.git
   cd rootfacts
   ```

   Note: For now my repo in private.

2. Install dependencies:

   ```bash
   npm install
   ```

## Development Server

Run the app in development mode with hot reload:

    ```bash
    npm run start-dev
    ```

The app will be available at http://localhost:8080.

## Production Build

Create an optimized production build:

```bash
npm run build
```

The output will be in the dist/ folder.

## Local Preview of Production Build

```bash
npm run serve
```

## PWA & Offline Support

- Manifest: manifest.json provides app name, icons, theme colors, and display settings.
- Service Worker: Generated by Workbox, caches all static assets and model files using strategies:
  - CacheFirst for models (.json, .bin, .wasm)
  - StaleWhileRevalidate for JS/CSS
  - NetworkFirst for API routes (if any)
- Installable: Meets all PWA installability criteria (HTTPS, manifest, SW, icons, etc.).
